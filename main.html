User Profile

Chat

Turns off the chat button everywhere in the app and stops any calls to the AI assistant — use this to stop incurring API costs without losing anything you've already asked it to remember or any of the other AI features (Plan my day, Training's weekly objectives/Today's session, Scan Food with AI). Everything else keeps working normally.
